Ce dossier est destiné à recevoir les fichiers PDF des romans (et
uniquement les PDF : les couvertures et la photo, elles, se déposent
dans le dossier images/, voir GUIDE-IMAGES-ET-PDF.md à la racine du
projet).

Déposez ici, avec exactement ces noms de fichiers :
  - les-couleurs-du-noir.pdf
  - deteste-moi-si-tu-peux.pdf

Dès qu'un fichier est présent avec le nom exact ci-dessus, le site le
détecte automatiquement (voir js/script.js, système de vérification de
disponibilité des PDF) et affiche les boutons "Ouvrir le PDF" /
"Télécharger" sur la page du roman correspondant. Tant que le fichier
est absent, le site affiche discrètement la mention "Bientôt disponible"
au lieu d'un lien cassé.

Vous pouvez supprimer ce fichier README.txt une fois les PDF ajoutés
(il n'est pas utilisé par le site).
