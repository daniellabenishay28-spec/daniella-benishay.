Placez ici les couvertures des romans, avec exactement ces noms de
fichiers :

  les-couleurs-du-noir.jpg
  deteste-moi-si-tu-peux.jpg

Chaque couverture est utilisée automatiquement à tous les endroits où
elle apparaît sur le site (accueil, page "Mes livres", page du roman
correspondant). Il suffit de remplacer le fichier existant par votre
propre couverture (même nom, même emplacement) pour que le site se
mette à jour partout à la fois — aucune modification de code requise.

Si un fichier est absent ou illisible, le site affiche à la place un
cadre élégant "Couverture à venir" plutôt qu'une image cassée.

Vous pouvez supprimer ce fichier README.txt une fois les couvertures
ajoutées (il n'est pas utilisé par le site).
