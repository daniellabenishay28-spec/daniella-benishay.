Placez ici la photo de Daniella, avec exactement ce nom de fichier :

  daniella.jpg

Le site l'utilise automatiquement à deux endroits (page d'accueil,
section "À propos de moi" ; page "À propos"). Il suffit de remplacer ce
fichier par votre propre photo (même nom, même emplacement) pour que le
site se mette à jour tout seul — aucune modification de code requise.

Si le fichier est absent ou illisible, le site affiche à la place un
cadre élégant "Photo à venir" plutôt qu'une image cassée.

Vous pouvez supprimer ce fichier README.txt une fois la photo ajoutée
(il n'est pas utilisé par le site).
